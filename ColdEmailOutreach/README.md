Automate collecting leads (company database in this case), enrich them with company info, and send personalized cold emails using Gmail API. Then track open/reply rates in a Flask dashboard

*Modules:*
•	Leads in DB
•	Gemini personalized emails
•	Gmail API sending
•	Tracking pixel for opens
•	Dashboard showing stats

Sample Dataset to test this project: https://www.kaggle.com/datasets/rockbottom73/leads-dataset?utm_source=chatgpt.com
