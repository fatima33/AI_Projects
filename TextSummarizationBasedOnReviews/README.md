In this project, I’ve built an AI-based text summarization system that automatically extracts customer reviews from Google Maps and generates a short, meaningful summary using Google’s Gemini model.

*Modules*
- Pyppeteer
- Asyncio
-  Google Generative AI, or Gemini

This project demonstrates how automation and AI can work together — using Python to collect data from the web, and large language models to make sense of it instantly.
